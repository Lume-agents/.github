Lume brings your AI agent sessions into one place. Keep an eye on them through
a discreet Orb, or open the Workspace for focused work with independent
terminals and project context.

Local use requires no Lume account. Agents keep their own provider connections.

## The project

The public [Lume monorepo](https://github.com/Lume-agents/Lume) contains desktop,
mobile, Node, extensions, and shared contracts. Remote agent control and
internet Relay transport are under development; available controls depend on
the agent integration.

Start with the [README](https://github.com/Lume-agents/Lume#readme), explore the
[mobile companion](https://github.com/Lume-agents/Lume/blob/main/MOBILE.md), or
report an issue in the [public tracker](https://github.com/Lume-agents/Lume/issues).
